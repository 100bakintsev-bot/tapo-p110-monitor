# Джерела та залежності

- [python-kasa](https://github.com/python-kasa/python-kasa) — локальні протоколи Tapo; зафіксована залежність `0.11.0.1`.
- [Реалізація модуля енергії](https://github.com/python-kasa/python-kasa/blob/master/kasa/smart/modules/energy.py).
- [TP-Link: стороння сумісність](https://www.tp-link.com/us/support/faq/4416/).
- [Обговорення TPAP](https://github.com/python-kasa/python-kasa/issues/1590).
- [tapo-tomqtt](https://github.com/michaelrmartins/tapo-tomqtt) — досліджений приклад читання voltage/current та публікації MQTT. MQTT до цього проєкту не додано.
- [tapo](https://github.com/mihai-dinculescu/tapo) — альтернативна бібліотека. Не використовується цим проєктом.
- [Termux](https://github.com/termux/termux-app) та [proot-distro](https://github.com/termux/proot-distro).

Проєкт не постачає код або бінарні файли цих залежностей. Їхні ліцензії та умови залишаються у відповідних upstream-проєктах.
