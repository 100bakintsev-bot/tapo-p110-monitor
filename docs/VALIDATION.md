# Перевірки

Дата підготовки публічної версії: 20.10.2026.

## Фізичний пристрій

Робочу реалізацію перевірено на Tapo P110(EU), hardware 1.0, firmware `1.4.8 Build 260804 Rel.045837`, у Termux із Debian/Python 3.13 та python-kasa 0.11.0.1.

Підтверджено читання напруги, струму, потужності та енергії. Частота у відповідях чотирьох перевірених методів відсутня. Не встановлювали точність приладу й не перевіряли всі можливі методи/прошивки.

Під час роботи приватного розгортання відбулося відключення живлення: розетка стала недоступною, збирач продовжив записувати невдалі спроби без підставлення 0 В. Підтверджено перезапуск процесу зі зміною PID і збереження історії. Автоматичне повернення показників після саме цього відключення в межах початкової перевірки ще не спостерігали.

## Публічна адаптація

Вилучено мережеві адреси/шляхи власника. Адреса задається через configure, каталог даних і часовий пояс — через змінні середовища. Приватний Telegram-бот замінено прикладом інтеграції. Це адаптація робочої версії для окремого встановлення, а не копія приватного сервера.

## Автоматичні тести

Очищений публічний пакет перевірено в окремому каталозі Debian: **12 тестів пройдено**, 20.10.2026. Тестова копія не змінювала робочий бот або його зчитувач.

`test_reader.py` перевіряє одиниці, реальний нуль, відсутню частоту, часткові відповіді, помилки з'єднання, приховування приватних полів та файлові дозволи.

`test_voltage.py` перевіряє агрегування, дублікати слотів, пропуски, застарілі дані, північ, відкриття наявної історії, недоступну базу, приклад інтеграції та повну 25-годинну добу з переходом часу.

Команда запуску — у README. Тести не звертаються до фізичної розетки та не замінюють перевірку після встановлення у новому середовищі.
