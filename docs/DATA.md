# Дані та формули

Шлях даних: **Tapo → локальний KLAP v2 → зчитувач → SQLite → текст особистого меню**. SSH потрібен тільки для доступу до телефона. Telegram-токен зчитувачу не потрібен.

## Запити

Після встановлення сесії бібліотекою викликаються чотири методи читання:

| Метод | Призначення |
|---|---|
| `get_device_info` | Модель, прошивка, стан реле, Wi-Fi та доступні стани |
| `get_energy_usage` | Енергія за день/місяць, поточна потужність |
| `get_current_power` | Резервне значення потужності |
| `get_emeter_data` | Напруга, струм, потужність |

`Device.connect` також виконує початкові запити читання, потрібні python-kasa. Код проєкту не викликає запис параметрів, перемикання реле або оновлення прошивки.

## Одиниці

| Показник | Перетворення |
|---|---|
| Напруга, В | `voltage_mv / 1000` |
| Струм, А | `current_ma / 1000` |
| Потужність, Вт | `power_mw / 1000`; резерв `get_energy_usage.current_power / 1000`; далі `get_current_power.current_power` без ділення |
| Енергія, кВт·год | `today_energy / 1000`, `month_energy / 1000` |
| Частота, Гц | Лише явне `frequency_hz`; на перевіреній P110 такого поля немає |

Нульовий струм при ненульовій потужності може траплятися у відповідях розетки: зчитувач не підміняє його розрахунковим струмом. Частота 50/60 Гц у паспорті не є виміряним значенням.

## Файли

- `latest.json` — остання спроба, включно з помилкою.
- `last_success.json` — остання спроба з хоча б однією успішною відповіддю; перевіряйте `complete`, окремі показники й час.
- `monitor-health.json` — `checked_at` (Unix UTC), `collector_ok`, `plug_reachable`, `complete`.
- `voltage.sqlite3` — хвилинні агрегати та службові метадані.
- `monitor.log` — обмежений за розміром журнал класів внутрішніх помилок.

JSON зчитувача містить UTC ISO-час, `reachable`, `read_only`, словник `methods`, `device`, `raw_energy`, `measurements`. Кожен показник має `value`, `unit`, `status`, `source`. Відсутнє значення — `null`. Ідентифікатори/координати/SSID не експортуються як значення пристрою; перелік назв повернутих полів може їх згадувати. Знімки все одно містять локальну адресу та інформацію про навантаження — не публікуйте їх без очищення.

## Історія

Для хвилини зберігаються кількість валідних значень `n`, сума `total`, мінімум/максимум і час їх спостереження, кількість спроб. Повторний запис у той самий десятисекундний слот ігнорується.

Середня за день = сума всіх валідних значень / їх кількість. Це середнє вибірки, не безперервне інтегрування й не середнє лише хвилинних середніх. Пропуски не заповнюються.

Приблизне охоплення = `min(100%, n × 10 секунд / час спостереження × 100%)`. Початок — пізніший із півночі або першого запуску збору. Це оцінка регулярності опитувань; вона не доводить наявність/відсутність електрики.

Доба визначається у налаштованому часовому поясі, включно з переходом літнього часу. Погодинний підсумок показує зміщення UTC, щоб розрізняти повторну годину. Зберігаються 366 днів хвилинних агрегатів.

Через 90 секунд без нового запису статус напруги в меню вважається несвіжим. Свіжа невдала спроба означає «вимірювання недоступне». Частіші зміни, ніж інтервал опитування, можуть залишитися непоміченими.
