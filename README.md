# Tapo P110 Voltage Monitor

Локальне читання напруги, струму, потужності й енергії **Tapo P110(EU)** через python-kasa та KLAP v2. Зберігає хвилинну історію напруги у SQLite й формує текст для наявного Telegram-бота. Команд перемикання розетки немає.

**Перевірена модель:** P110(EU), hardware 1.0, firmware `1.4.8 Build 260804 Rel.045837`. На цій прошивці напруга доступна, частота у перевірених відповідях відсутня. Сумісність з іншими моделями/прошивками не заявлена.

## Можливості

- Одноразовий знімок JSON або автоматичне опитування приблизно кожні 10 секунд.
- Напруга, струм, потужність, енергія за день і місяць; доступні метадані пристрою.
- Середня напруга, мінімум/максимум із часом та погодинний текстовий підсумок.
- Хвилинні агрегати за останні 366 днів; SQLite основного бота не змінюється.
- Пропуски та застарілі дані не замінюються нулями.
- Приклад підключення до існуючого бота без другого polling.
- Запуск через runit у Termux і коректне завершення групи процесів proot.

## Почати

На розетці в застосунку Tapo ввімкніть сумісність зі сторонніми застосунками. Налаштуйте постійну локальну адресу через DHCP reservation на маршрутизаторі, якщо потрібно. Повна інструкція: [Termux і Linux](docs/INSTALL.md).

Після встановлення залежностей:

```sh
chmod +x run
./run configure --host YOUR_PLUG_IP
./run
./run --samples 3 --interval 10
```

Замість `YOUR_PLUG_IP` укажіть адресу власної розетки. Email і пароль вводяться локально; не передавайте їх у чат, GitHub чи Google Диск.

За замовчуванням конфігурація й дані зберігаються в `$HOME/.local/share/tapo-p110-monitor`. Змінити каталог можна через `TAPO_DATA_DIR`, часовий пояс — через `TAPO_TIMEZONE` (типово `Europe/Kyiv`). Використовуйте однакові значення для читача, монітора й бота.

## Перевірка без розетки

У Linux-середовищі з установленими залежностями:

```sh
.venv/bin/python -m unittest discover -s . -p 'test_*.py' -v
```

Тести використовують підмінений пристрій, не читають реальні credentials і не перемикають реле.

## Важливі межі

Недоступність Wi-Fi або розетки не доводить відключення світла. Залишайте свій чинний датчик джерелом стану електропостачання. Потужність та енергія стосуються лише навантаження через розетку. Короткі зміни між опитуваннями можуть бути пропущені. Це журнал вимірювань, а не реле захисту чи повірений аналізатор якості електроенергії.

Пороги аварійних попереджень не задані; автоматичних повідомлень про вихід за межі немає.

Публічний пакет підготовлено 20.10.2026 з робочої реалізації. Він не містить приватного Telegram-бота, мережевих адрес власника, паролів, SSH-ключів чи фактичної історії споживання.
