# Підключення до наявного бота

Проєкт не створює Telegram-бота, не зберігає токен, не запускає polling і не розсилає повідомлень. Він формує текст, який використовує ваш наявний обробник.

1. Зробіть резервну копію коду й бази свого бота.
2. Додайте каталог цього проєкту до `PYTHONPATH` бота або скопіюйте `voltage_data.py` поруч із його кодом.
3. Установіть однакові `TAPO_DATA_DIR` та `TAPO_TIMEZONE` для бота і збирача. Бот повинен мати доступ на читання SQLite; не робіть каталог даних загальнодоступним.
4. Підключіть три функції з [прикладу](../examples/bot_integration.py).

```python
import voltage_data

# До вашого чинного тексту стану світла:
text = existing_status_text + voltage_data.status_text()

# Обробник кнопки «⚡ Напруга за день»:
text = voltage_data.day_text(hourly=True)

# До звіту за конкретний день:
text = existing_daily_report + "\n\n" + voltage_data.day_text(report_date)
```

Кнопка звичайної Telegram-клавіатури:

```python
{"text": "⚡ Напруга за день"}
```

Додайте її до існуючого меню та зіставте текст із вашим обробником. Для особистого меню перевіряйте `chat.type == "private"` у своєму боті. Збирач не повинен надсилати нове повідомлення кожні 10 секунд: він лише оновлює локальні дані. У канал можна додати підсумок у вже наявну заплановану розсилку.

Залиште чинний датчик джерелом наявності світла. Навіть якщо напруга недоступна, кнопки та основна логіка бота повинні продовжувати працювати. Читання історії має короткий timeout і повертає зрозумілий текст при помилці.

Сумарний текст вашого повідомлення повинен вкладатися в ліміт Telegram. Власний погодинний підсумок перевірено на добі з 25 годинами; довжина додаткового тексту вашого бота залежить від вашої реалізації.

Пороги й час підтвердження попереджень потрібно погодити перед додаванням автоматичних сповіщень. У цій версії їх немає.
