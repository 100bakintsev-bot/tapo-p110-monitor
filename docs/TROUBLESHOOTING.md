# Діагностика

## TPAP / UnsupportedDeviceError

Перевірена P110 рекламує TPAP в автоматичному виявленні. Встановлена версія python-kasa підключається через явно заданий KLAP v2. У застосунку Tapo ввімкніть сумісність зі сторонніми застосунками; код уже обходить автоматичне визначення TPAP.

## AuthenticationError

Перевірте Tapo-акаунт і режим сумісності. Повторіть `./run configure --host YOUR_PLUG_IP` у своєму інтерактивному терміналі. Не публікуйте пароль, credentials або повні трасування сторонніх бібліотек.

## Недоступна напруга

Подивіться `latest.json`: `reachable`, `methods`, `measurements.voltage.status` і час. Якщо сама розетка недоступна, перевірте мережу/живлення незалежним способом. Це не причина перезапускати Telegram polling.

## Служба не працює

```sh
sv status "$PREFIX/var/service/tapo-p110-monitor"
cat "$TAPO_DATA_DIR/monitor-health.json"
```

Якщо `TAPO_DATA_DIR` не заданий у поточному терміналі, використайте `$HOME/.local/share/tapo-p110-monitor`.

`collector_ok=true` разом із `plug_reachable=false` означає, що збирач працює, але вимірювання недоступні. Не плутайте це із зависанням процесу.

`monitor_service.py` завершує всю групу proot і дочірній Python. Звичайний сигнал TERM лише до proot під час перевірки не зупиняв Python надійно, тому адаптер є частиною служби.

## Контроль свіжості

Для зовнішнього watchdog орієнтиром є вік `monitor-health.json` понад 120 секунд або повторний `collector_ok=false`. У приватному розгортанні це перевіряє наявний watchdog з обмеженням частоти перезапусків. Його код не входить до публічного пакета, оскільки він керує іншими службами власника.

У самостійному пакеті runit відновлює завершений процес; окремого watchdog для зависання немає. Мережеві запити обмежені timeout. Якщо потрібен зовнішній watchdog, перевіряйте кілька послідовних помилок і обмежуйте частоту перезапусків. Не перезапускайте через саму недоступність розетки.

## Android завершує Termux

Налаштування енергозбереження, старт після перезавантаження та системні обмеження процесів залежать від телефона. Сам Python не може гарантувати відновлення після завершення всього Termux. Пакет не змінює Android через ADB.

## Після оновлення

Збережіть попередній код і приватну базу. Запустіть тести без реальної розетки, потім один живий знімок і службу. Переконайтеся, що є лише один збирач для розетки й лише наявний polling вашого бота.
